GitHub 토큰 등록

웹에서 바로 사이트에 반영하려면 GitHub 토큰이 한 번 필요합니다.

토큰은 이 브라우저에만 저장되고 서버로 전송되지 않습니다. 공용 PC에서는 등록하지 말고 ‘파일로 저장’을 쓰세요.
  1. 토큰 만들기 페이지를 엽니다
  2. Repository access → Only select repositories → 이 저장소만 선택
  3. Permissions → Repository permissions → Contents 를 Read and write 로
  4. Generate token 후 github_pat_… 값을 아래에 붙여넣기
